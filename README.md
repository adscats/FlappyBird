# Flappy Bird

A simple arcade game where you guide a bird through gaps between pipes and try to fly as far as possible.

## Objective

Fly as far as you can without hitting any pipes. Collect coins during your run and spend them on bird skins.

## How to Play

- Tap the screen to make the bird flap upward.
- When you are not tapping, the bird falls due to gravity.
- Guide the bird through the gaps between pipes.
- Hitting a pipe ends the game.

## Features

### Minimum Viable Version

- A single game screen
- One playable bird
- A stationary background
- Repeating pipes
- Simple controls and collision-based game over

### Coins and Bird Skins

- Collect coins while flying.
- Coins appear between pipes.
- Spend collected coins in a small shop to unlock bird skins.
- Skins change only the bird’s appearance and do not affect gameplay.

### Chests and Power-Ups

Chests can provide random rewards, such as:

- A speed change, such as **0.5× speed**
- **10 coins**
- **10 bonus points** added to the score

## Possible Future Improvements

- Add more bird skins and shop items.
- Add different chests and rewards.
